# Pokermon

**Pokermon** is a collaborative planning tool built for agile teams. Designed to make SCRUM poker sessions seamless and interactive, Pokermon leverages **Nuxt.js** and **Socket.IO** for a real-time experience. While the name might spark some nostalgia, Pokermon is not affiliated with Pokemon or Nintendo in any way.

---

## Features

- **Real-Time Collaboration**: Enables team members to vote and interact simultaneously through WebSockets.
- **Customizable Sessions**: Set up and tailor planning poker sessions to suit your team's needs.
- **Responsive Design**: Works on desktop, tablet, and mobile devices for planning on the go.
- **Nuxt.js-Powered UI**: Fast and sleek interface for a smooth user experience.
- **Secure Communication**: Ensures the privacy and integrity of your planning sessions.

---

## Why Use Pokermon?

Pokermon simplifies sprint planning by making it easy for distributed teams to:

1. **Estimate Effort**: Use story points to reach consensus on task complexity.
2. **Encourage Engagement**: Allow every team member to have an equal say in the planning process.
3. **Save Time**: Reduce ambiguity and speed up sprint planning sessions.

---

## How It Works

1. **Create a Session**: Start a new planning session and share the unique room link with your team.
2. **Join and Vote**: Team members join the session, view the story, and vote anonymously.
3. **Reveal Votes**: Once all votes are in, reveal them to spark discussion and reach consensus.

## Setup

Make sure to install the dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm run dev

# yarn
yarn dev

# bun
bun run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build

# pnpm
pnpm run build

# yarn
yarn build

# bun
bun run build
```

Locally preview production build:

```bash
# npm
npm run preview

# pnpm
pnpm run preview

# yarn
yarn preview

# bun
bun run preview
```

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.

## Technologies Used

- **[Nuxt.js](https://nuxtjs.org/)**: Framework for building Vue.js applications with server-side rendering and powerful features.
